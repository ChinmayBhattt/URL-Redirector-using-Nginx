🗺️ Request Routing Architecture

1. Client Browser (Port 80) ➔ Nginx Server Block (listen 80)
2. Static Requests (/, /style.css) ➔ Served directly from disk via root & index
3. Dynamic API (/api/*, /redirect) ➔ Forwarded to Node.js on port 3000 via proxy_pass
4. Custom Redirect (/google) ➔ Redirected instantly to google.com via return 302
5. Unknown Route (/* not found) ➔ Custom error page rendered via error_page 404
